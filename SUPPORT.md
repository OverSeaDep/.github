# 支持 / Support

简体中文 | English

## 公开项目 / Public Projects

- **先读文档**：先阅读目标仓库的 `README.md`、`SKILL.md` / 文档目录，多数疑问（安装、用法、已知限制）已有答案。
- **问题与建议**：使用仓库的 GitHub Issues（默认表单模板会引导填写）。
- **代码贡献**：见各仓库的 `CONTRIBUTING.md`（无自带文件时使用组织默认 `CONTRIBUTING.md`）。
- **安全漏洞**：按各仓库 `SECURITY.md`（或组织默认 `SECURITY.md`）的渠道私下报告。

- **Read the docs first**: most questions (installation, usage, known limitations) are already answered in the repository's `README.md`, `SKILL.md`, or docs directory.
- **Issues & suggestions**: open a GitHub Issue in the target repository (default form templates guide you).
- **Code contributions**: see the repository's `CONTRIBUTING.md` (fall back to the organization default).
- **Security vulnerabilities**: report privately through the repository's `SECURITY.md` (or the organization default).

## 组织内部成员 / Organization Members

- 组织内大多数仓库为私有仓库，仅授权成员可见；访问权限问题请联系组织管理员。
- 内部协作请优先使用仓库内的 AGENTS / 专题文档约定；跨仓库问题在对应的内部讨论渠道提出，不要复制客户数据或敏感内容到公开处。

- Most organization repositories are private and visible only to authorized members; contact an organization admin for access.
- For internal collaboration, follow each repository's AGENTS / topic-document conventions; raise cross-repository questions in the appropriate internal channel, and never copy customer data or sensitive content into public places.

## 支持边界 / What We Do Not Support

- 本组织的研究报告与知识库用于决策支持，不构成投资、法律、税务或市场进入意见；使用前请独立核验最新来源。
- 本组织的公开工具以「现状」提供；生成类服务（API、算力）费用与账号由使用者自行负责。

- Research reports and knowledge bases here support decisions and are not investment, legal, tax, or market-entry advice; independently verify the latest sources before use.
- Public tools are provided "as is"; usage costs and accounts for generation services (APIs, compute) are the user's responsibility.
